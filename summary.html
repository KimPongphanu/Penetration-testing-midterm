เส้นทางการเรียนรู้ Penetration Testing ตามวงจรชีวิตการทดสอบเจาะระบบ

Penetration Testing Execution Standard (PTES) — จากผู้ไม่รู้เป้าหมาย ถึงการควบคุมระบบอย่างเบ็ดเสร็จ

ภาพรวมของหลักสูตร (Overview)

เนื้อหาตั้งแต่ Lecture 1 ถึง Lecture 7 ถูกร้อยเรียงตาม วงจรชีวิตของการทดสอบเจาะระบบจริง (Penetration Testing Execution Standard - PTES) แบบ Step-by-Step

เป้าหมายหลักที่ซ่อนอยู่ (Hidden Objective) คือการฝึกทักษะให้คิดและลงมือทำอย่างเป็นระบบแบบ Offensive Security Professional (Ethical Hacker) โดยเริ่มจากการไม่รู้อะไรเลยเกี่ยวกับเป้าหมาย ไปจนถึงการเข้าควบคุมระบบและยึดข้อมูลสำคัญได้อย่างเบ็ดเสร็จ

สรุปเส้นทางการเรียนรู้ (The Big Picture)
Scope/Setup (L1) → Recon (L2) → Scan (L3) → Enumerate (L4) → Analyze (L5) → Exploit (L6) → Post-Exploit/Crack (L7)

แผนภาพความสัมพันธ์และ Objective ของแต่ละ Lecture

L1

Foundation & Methodology (ปูพื้นฐานและกฎกติกา)

Objective: ทำความเข้าใจขอบเขต จริยธรรม และแยกความแตกต่างระหว่างการสแกนหาช่องโหว่ (VA) กับการเจาะระบบจริง (PT) พร้อมเตรียมสภาพแวดล้อมแล็บ (Kali & Metasploitable2)

➔ จุดเชื่อมต่อไปยัง L2: เมื่อมีแล็บพร้อมแล้ว สเต็ปแรกของการโจมตีคือการเริ่มหาข้อมูลเป้าหมาย
L2

Passive Reconnaissance & Linux Fundamentals (สำรวจข้อมูลภายนอก)

Objective: เก็บข้อมูลเป้าหมายจากแหล่งสาธารณะ (OSINT / Google Dorking / WHOIS) โดยยังไม่แตะต้องระบบตรงๆ เพื่อไม่ให้เป้าหมายรู้ตัว

➔ จุดเชื่อมต่อไปยัง L3: เมื่อได้ขอบเขต IP และ Domain กว้างๆ แล้ว ต้องเริ่มส่งแพ็กเก็ตเข้าไปสำรวจโดยตรง
L3

Active Scanning & Host Discovery (สแกนหาพอร์ตและบริการ)

Objective: ใช้ Nmap ยิงโพรบตรวจสอบว่ามีโฮสต์ไหนเปิดอยู่ (Host Discovery) และมีประตู/พอร์ตใดเปิดไว้บ้าง (-sS, -sT, -sV, -O)

➔ จุดเชื่อมต่อไปยัง L4: เมื่อรู้ว่าพอร์ตใดเปิดอยู่ ต้องเจาะลึกเข้าไปดูรายละเอียดการตั้งค่าของแต่ละพอร์ต
L4

Service Enumeration & Deep Inspection (เจาะลึกรายละเอียดบริการ)

Objective: ดึงข้อมูลเชิงลึก (Users, Shares, Configs, Hidden Paths) จากโปรโตคอลสำคัญ เช่น SMB (enum4linux, smbclient), RPC (showmount), และ Web (http-enum)

➔ จุดเชื่อมต่อไปยัง L5: เมื่อได้รายการเวอร์ชันและโครงสร้างภายในครบแล้ว ต้องนำไปเทียบกับฐานข้อมูลเพื่อหาว่ามีช่องโหว่ใดบ้าง
L5

Vulnerability Assessment & Scoring (วิเคราะห์และประเมินช่องโหว่)

Objective: สแกนเปรียบเทียบหาช่องโหว่ที่มีอยู่จริง (Known CVEs) ด้วย Nmap Vuln Scripts, Nessus, และ OWASP ZAP พร้อมประเมินความรุนแรงด้วยคะแนน CVSS

➔ จุดเชื่อมต่อไปยัง L6: เมื่อได้รายชื่อช่องโหว่ระดับ Critical/High แล้ว ต้องพิสูจน์ (PoC) ด้วยการเจาะจริงว่าเข้าถึงระบบได้หรือไม่
L6

System Exploitation (การเจาะระบบเพื่อยึดครอง)

Objective: นำ CVE ที่ตรวจพบมาเลือกใช้ Exploit + Payload ใน Metasploit หรือสคริปต์เฉพาะทางเพื่อเจาะเอา Initial Access / Root Shell

➔ จุดเชื่อมต่อไปยัง L7: หลังจากเจาะเข้าไปในระบบได้แล้ว มักจะได้สิทธิ์เพียงระดับหนึ่ง หรือได้ไฟล์สำคัญอย่าง /etc/shadow ออกมา จึงต้องทำ Post-Exploitation ต่อ
L7

Password Cracking & Post-Exploitation (การถอดรหัสผ่านและการคงสิทธิ์)

Objective: นำข้อมูลรหัสผ่านที่ดึงมาจากขั้นตอน Exploitation (เช่น /etc/shadow) มาถอดรหัสด้วย John the Ripper / Hashcat หรือทำ Brute-force ซ้ำด้วย Hydra เพื่อยึดบัญชีอื่นๆ ในระบบ

สรุปบทเรียนสำคัญ (The Key Takeaway)

หลักสูตรนี้วางโครงสร้างเพื่อให้เห็นว่า "การแฮกระบบไม่ใช่การสุ่มยิงมั่ว" แต่เป็นกระบวนการต่อเนื่องแบบลูกโซ่ (Kill Chain) ที่ข้อมูลจากขั้นตอนก่อนหน้าจะเป็นกุญแจสำคัญให้ขั้นตอนถัดไปประสบความสำเร็จเสมอ

กล่าวคือ ข้อมูล (Intelligence) ที่เก็บได้ในเฟส Reconnaissance จะกำหนดทิศทางของ Scanning ผลการสแกนจะชี้เป้าไปยังบริการที่ต้อง Enumeration ผลการ Enumerate จะนำไปสู่การระบุช่องโหว่ ช่องโหว่ที่ถูกยืนยัน (Validate) จะถูกนำไป Exploit และผลลัพธ์จากการ Exploit (เช่น ไฟล์ /etc/shadow) จะถูกใช้ต่อในขั้นตอน Password Cracking เพื่อยกระดับสิทธิ์และขยายผลการโจมตี — เป็นวงจรที่ต่อเนื่องกันครบถ้วน ตามมาตรฐาน PTES ตั้งแต่ Pre-engagement ไปจนถึง Reporting

PTES : 7 Phases มาตรฐาน
Pre-engagement → Intelligence Gathering → Threat Modeling → Vulnerability Analysis → Exploitation → Post Exploitation → Reporting
