วิชา Penetration Testing and Protection (0406136051)

1. หลักการจัดเก็บรหัสผ่าน (Password Hashing & Salting)

รหัสผ่านจะถูกจัดเก็บในรูปของ One-way Hash ที่ไม่สามารถแปลงกลับได้โดยตรง เมื่อถูกแฮชแล้วผู้ใช้จะเห็นเพียงสตริงที่มีความยาวคงที่ ระบบ Linux จะมีการเพิ่ม Salt (ค่าสุ่ม) เพื่อป้องกันไม่ให้รหัสผ่านเดียวกันมีค่าแฮชซ้ำกัน

กลไกรายละเอียด
DES (crypt)ใช้ Salt ขนาด 12-bit เพื่อปรับ DES encryption ให้เป็น One-way Hash function
Bcrypt (Blowfish)ใช้โดย OpenBSD ใช้ Salt ขนาด 128-bit สร้าง Hash value ขนาด 192-bit

2. การระบุประเภทแฮชในไฟล์ /etc/shadow

สัญลักษณ์นำหน้าประเภทแฮช
$1$MD5 (md5crypt)
$2a$Blowfish (Bcrypt)
$5$SHA-256 (sha256crypt)
$6$SHA-512 (sha512crypt)
$y$ หรือ $7$yescrypt
ไม่มีสัญลักษณ์นำหน้าDES (crypt)

3. ประเภทของการโจมตีรหัสผ่าน (Types of Password Attacks)

ประเภทรายละเอียด
Passive Onlineดักจับทราฟฟิกข้อมูลบนเครือข่ายโดยไม่เข้าไปยุ่งกับการสื่อสาร เช่น Wire Sniffing, Man-in-the-Middle (MitM) และ Replay Attacks (ดักจับแล้วส่งซ้ำเพื่อเลี่ยง Authentication)
Active Onlineพยายามเดารหัสผ่านกับระบบเป้าหมายโดยตรง เช่น Brute-force หรือ Password Guessing — ใช้เวลานาน ใช้แบนด์วิดท์สูง และตรวจจับได้ง่าย ปัญหาหลักคือรหัสผ่านที่ไม่แข็งแรง (Bad Passwords)
Offlineนำไฟล์แฮชออกมาแคร็กบนเครื่องตนเอง ทำได้รวดเร็วและไม่ถูกตรวจจับโดยระบบเป้าหมาย เทคนิค: Brute Force, Dictionary Attacks, Rainbow Tables
Non-electronicการโจมตีที่ไม่ใช้ระบบอิเล็กทรอนิกส์ เช่น Social Engineering

4. Wordlist (พจนานุกรมรหัสผ่าน)

  • Wordlist คือคอลเลกชันรหัสผ่านที่เก็บเป็นข้อความธรรมดา (Plaintext) ซึ่งเป็นตัวหลักของการโจมตีแบบ Brute Force / Dictionary
  • Wordlist มักได้มาจากข้อมูลการรั่วไหล (Data Breaches) หรือสร้างขึ้นเองตามความต้องการ
  • RockYou: ไฟล์ wordlist ยอดนิยมบน Kali อยู่ที่ /usr/share/wordlists/rockyou.txt.gz — ต้องแตกไฟล์ก่อน: sudo gzip -d /usr/share/wordlists/rockyou.txt.gz
  • Crunch: เครื่องมือสร้าง Wordlist ตามเงื่อนไข
    • crunch 4 4 abcdefghijklmnopqrstuvwxyz — สร้างคำ 4 ตัวอักษรจากตัวอักษรพิมพ์เล็ก
    • crunch 8 8 abcdefghijklmnopqrstuvwxyz0123456789 -o wordlist.txt — สร้างคำ 8 ตัวอักษรและบันทึกลงไฟล์
    • crunch 8 8 abcdefghijklmnopqrstuvwxyz -t %%%%%%-%%%%%% — ใช้ Template กำหนดรูปแบบคำ

5. เครื่องมือหลักสำหรับการถอดรหัสผ่าน (Tools)

เครื่องมือรายละเอียด
Hydraเครื่องมือ Brute-force บน Network Services (Active Online) ที่เร็วมาก รองรับหลายบริการ เช่น FTP, SSH ตัวอย่าง: hydra -L users.txt -P passwords.txt <Target_IP> ftp
John the Ripperเครื่องมือโอเพนซอร์สยอดนิยมสำหรับ Offline Hash Cracking รองรับหลายแพลตฟอร์ม (Unix, Windows, macOS) และหลายประเภทแฮช
Hashcatเครื่องมือ Command Line ที่ทรงพลังสำหรับแคร็กแฮช รองรับ MD5, SHA-1, SHA-256, bcrypt และอื่นๆ มีโหมด Brute-force, Dictionary และ Hybrid Attacks
Aircrack-ngชุดเครื่องมือทดสอบความปลอดภัยเครือข่ายไร้สายและแคร็กรหัสผ่าน WEP / WPA / WPA2-PSK

รูปแบบคำสั่ง Hashcat

  • hashcat -m <hash_type> -a <attack_mode> hashfile wordlist
  • -m ระบุประเภทแฮช เช่น 500 = MD5-Crypt, 0 = MD5, 100 = SHA-1, 3200 = bcrypt
  • -a ระบุโหมดการโจมตี: 0 = Straight (Dictionary), 1 = Combination, 3 = Brute-force, 6 = Hybrid Wordlist + Mask, 7 = Hybrid Mask + Wordlist, 9 = Association
  • ตัวอย่าง: hashcat -m 500 -a 0 meta_shadow_cut /usr/share/wordlists/rockyou.txt --potfile-disable

6. รายละเอียดขั้นตอนปฏิบัติการ Lab (Step-by-Step Practical Guide)

ตอนที่ 1: การแคร็กรหัสผ่านแบบ Online ด้วย Hydra

  • สร้างไฟล์พจนานุกรม: จัดเตรียมไฟล์ users.txt และ passwords.txt ผ่านคำสั่ง nano users.txt (ใส่ root, admin, user, test, ubuntu, postgres, oracle, ftpuser, shared ฯลฯ) และ cp users.txt passwords.txt
  • สั่งรัน Hydra โจมตีบริการ FTP: รันคำสั่ง hydra -L users.txt -P passwords.txt <Target_IP> ftp เพื่อค้นหาคู่บัญชีและรหัสผ่าน
  • ยืนยันการเข้าถึง: ทดสอบล็อกอินเข้าใช้งานผ่านคำสั่ง ftp <Target_IP> แล้วรันคำสั่ง FTP เช่น ls, pwd

ตอนที่ 2: การจัดการและสร้าง Wordlist

  • แตกไฟล์ RockYou: ใช้คำสั่ง sudo gzip -d /usr/share/wordlists/rockyou.txt.gz และตรวจสอบจำนวนคำด้วย wc -l rockyou.txt
  • สร้าง Wordlist ด้วย Crunch: ใช้คำสั่ง crunch 4 4 abcdefghijklmnopqrstuvwxyz -o wordlist_4char.txt เพื่อสร้างชุดคำตามเงื่อนไขที่กำหนด

ตอนที่ 3: การแคร็กรหัสผ่านแบบ Offline ด้วย John the Ripper และ Hashcat

  • ดึงและเตรียมไฟล์แฮช: ใช้คำสั่ง sudo cat /etc/shadow เพื่อดูแฮชรหัสผ่านบน Metasploitable2 แล้วบันทึกลงไฟล์ เช่น nano meta_shadow (หรือ sudo cat /etc/shadow > pass_shadow)
  • รวมไฟล์ passwd กับ shadow (ถ้าจำเป็น): คัดลอก /etc/passwd และ /etc/shadow จากเครื่องเป้าหมาย แล้วรวมด้วยคำสั่ง unshadow passwordmeta2.txt shadowmeta2.txt > hashes.txt และล้างผลลัพธ์เดิมด้วย rm ~/.john/john.pot
  • แคร็กด้วย John the Ripper: รันคำสั่ง john --format=crypt meta_shadow หรือระบุ Wordlist ด้วย john --format=md5crypt --wordlist=/usr/share/wordlists/rockyou.txt meta_shadow
  • แสดงผลลัพธ์: ใช้คำสั่ง john --show meta_shadow เพื่อดูรหัสผ่านที่ถอดรหัสได้
  • แคร็กด้วย Hashcat: ตัดเฉพาะส่วนที่ต้องการด้วย cp meta_shadow meta_shadow_cut แล้วรันคำสั่ง hashcat -m 500 -a 0 meta_shadow_cut /usr/share/wordlists/rockyou.txt --potfile-disable สำหรับแฮชแบบ MD5-Crypt (อาจเพิ่ม Rule: -r /usr/share/hashcat/rules/best66.rule)
  • ทดลองสร้างผู้ใช้เพื่อฝึก: สร้างผู้ใช้ test1 (รหัส 12345) และ test2 (รหัส qwerty) ด้วย adduser แล้วลองแคร็ก pass_shadow ที่คัดลอกจาก /etc/shadow

ตอนที่ 4: การแคร็กรหัสผ่านเครือข่ายไร้สายด้วย Aircrack-ng

  • แคร็กคีย์ WEP: แตกไฟล์ Capture Packet tar -xf wepchallenge.tar.gz แล้วรัน aircrack-ng -b e4:7d:eb:31:10:9a wepchallenge*.cap (ช่องโหว่ของ WEP เกิดจาก IV ที่สั้นเกินไปและ Password คงที่ ทำให้มี Data Packet ที่ใช้ IV ซ้ำ)
  • แคร็กคีย์ WPA/WPA2: แตกไฟล์ wpachallenge.tar.gz รันคำสั่ง aircrack-ng -w /usr/share/wordlists/rockyou.txt -b e4:7d:eb:31:10:9a wpachallenge*.cap ร่วมกับไฟล์ Dictionary
