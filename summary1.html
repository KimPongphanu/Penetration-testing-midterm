L1 · Foundation & MethodologyPTES: Pre-engagement / Setup

Penetration Testing = Ethical Hacking: จำลองโจมตีอย่างได้รับอนุญาต เพื่อค้นช่องโหว่ก่อนผู้ไม่หวังดี — ประเมิน controls ครบ Technological / Procedural / Operational ต้องมี ROE อนุมัติก่อนเริ่ม

Pentester: จำลอง cyber attack กับระบบองค์กร ให้องค์กรเข้าใจ weakness + แนวทาง mitigate ใช้ TTP เดียวกับ attacker เพื่อชี้ business impact ของจุดอ่อน

Why essential / Benefits
  • Uncover hidden weaknesses · Improve security posture · Reduce breach risk
  • Compliance: PCI DSS, HIPAA · Build confidence · Stay ahead of attackers
  • หา hidden vulns / real-time web vulns · ทดสอบ WAF + cyber-defense capability
  • เจอ Misconfiguration · ลดค่าใช้จ่าย incident · เพิ่ม Security Awareness · ทักษะทันภัยคุกคาม
Terms / เปรียบเทียบรายละเอียด
Red Teamingadversarial กับองค์กร เลียนแบบ attacker จริง พยายาม stealth ไม่ให้ถูกตรวจจับ
Pentest vs White HatPT: structured framework/phases + รายงานชัด | White Hat: กว้าง/creative เช่น social engineering, zero-day, defensive tooling
VA vs PTVA เช็คระบบเทียบ known vulnerabilities (กว้าง) | PT เจาะผ่าน defenses พิสูจน์ impact (ลึก) — objective ต่างกัน ใช้คู่กันไม่แทนกัน
Testing depthVuln Scan ⊂ Vuln Assessment (+validation) ⊂ Pentest (+exploitation) ⊂ Red Team (ทดสอบ blue team)
Categories of test
  • Black box: ไม่ให้ข้อมูล (มีแค่ IP ranges) — external test ทั่วไป
  • White box: ให้เกือบหมด incl. source code → static/dynamic analysis — internal/onsite
  • Gray box: ข้อมูลบางส่วน เช่น user account ระดับทั่วไป
  • By target: Network / Physical (กล้อง ล็อก sensors) / Web app / Wireless

ROE (Rules of Engagement)
  • "Permission to hack" + NDA ลงนามทั้งสองฝ่าย · Scope · duration start/end · methodology · goals
  • Allowed/disallowed techniques (DoS ได้ไหม) · liabilities/responsibilities กำหนดล่วงหน้า
Lab setup
  • Kali Linux: tools ครบ info gathering / vuln assessment / webapp / DB / password / wireless / exploitation / sniffing-spoofing
  • Metasploitable: v1 (2010 เก่า), v2 (2012 — เป้าหมายหลัก Linux vulnerable by design), v3 (เพิ่ม Windows)
  • DVWA: เว็บฝังช่องโหว่ฝึก SQLi / XSS / insecure config
  • VirtualBox/VMware: Host-Only / Internal network ให้ Kali ↔ Metasploitable2 คุยกันได้

Lab steps (Recon)
  1. ตรวจ interface/IP: ip a (Kali ได้ IP วง lab ถูกต้อง)
  2. ทดสอบเชื่อมต่อ: ping -c 4 <Target_IP> — ไม่มี packet loss
  3. whois target.com — domain + name servers
  4. DNS records: nslookup -type=ns|mx, host -a target.com
  5. Dorking บน browser: site:/inurl:/filetype:
  6. mkdir -p ~/Pentest_Labs/Lab2 → cd → nano user_list.txt (admin/root/msfadmin 1 ชื่อ/บรรทัด)
  7. ตรวจสอบ: ls -la, cat user_list.txt

L3 · Scanning & Port Scanning (Nmap)Active — เริ่มส่งแพ็กเก็ตจริง
Objectives & types
  • Objectives: หา live systems · active/open ports · OS fingerprint · services listening · target IP (Metasploit มี db_nmap built-in)
  • Types: Port scan (service↔well-known port, list ใน /etc/services) · Network scan (หา active hosts) · Vulnerability scan (automated known vulns)
Port stateMechanics
Openมี server process listen — SYN → SYN/ACK กลับ
Closedไม่มี service — SYN → RST กลับ
Filteredfirewall/iptables drop — ไม่ตอบกลับเลย
TechniqueBehavior
TCP Connect -sThandshake เต็ม SYN→SYN/ACK→ACK แล้ว RST; accurate, ไม่ต้อง root, log ง่าย (vanilla/full connect)
SYN half-open -sSSYN→SYN/ACK→ส่ง RST ทันที; stealth ลด logging, ต้อง sudo/root
FIN -sFส่ง FIN flag; silent=open, RST=closed — หลบ logging บาง firewall
XMAS -sXFIN+URG+PUSH; silent=open, RST=closed
NULL -sNไม่มี flag เลย; silent=open, RST=closed/filtered
ACK -sAทดสอบ stateful firewall/ACL: silent=stateful filtering, RST=packet ผ่านถึง dest
UDP -sUICMP port-unreachable=closed, silence=open/filtered; ช้ากว่า TCP (DNS/DHCP/SNMP)
FTP bounce -bใช้ FTP server ส่งแทน — ซ่อนตัว attacker (anonymous relay)
Host discovery

Step แรกของ network pentest = รู้ว่าอะไร alive · nmap -sP|-sn <IP> ping scan · sweep ทั้งวง nmap -sP 192.168.37.1/24 · เร็วสุด: sudo masscan --ports 0-65535 <IP> · External = จำกัดเฉพาะ IP ใน scope, Internal = scan ทั้ง subnet/subnets

Common ports

21 FTP · 22 SSH · 23 Telnet · 25 SMTP · 53 DNS · 80 HTTP · 110 POP3 · 143 IMAP · 161 SNMP · 443 HTTPS · 139 NetBIOS · 445 SMB · 3389 RDP

Detection options
  • -sV probe ถามเวอร์ชัน service (Apache, vsFTPd, OpenSSH…)
  • -O OS fingerprint จารูปแบบ TCP/IP stack response
  • -sC รัน default NSE scripts ตามพอร์ตที่พบ
  • -A aggressive = -sV + -O + -sC + traceroute → nmap -n -A -T5 <IP>
  • -p- scan ครบ 65,535 ports · -T0..T5 timing paranoid→insane
  • Output files: -oN normal · -oG greppable · -oX XML · -oA name ทุก format (.nmap/.xml/.gnmap)
Lab steps (ตามลำดับ)
  1. nmap -sn 192.168.56.0/24 → หา IP เครื่อง target
  2. sudo nmap -sS <Target_IP> top-1000 ports stealth
  3. nmap -sT -p 21,80,445 <Target_IP> connect scan เจาะจงพอร์ต
  4. nmap -sV <Target_IP> version detection
  5. sudo nmap -O -T4 <Target_IP> OS fingerprint + speed
  6. sudo nmap -A <Target_IP> aggressive ครบชุด
  7. nmap -sT -p 80 <Target_IP> -oN mscan.txt → cat mscan.txt
  8. nmap -sV <Target_IP> -oA lab3_scan_results ทุก format
  9. Exercise: sudo nmap -sS -sV -sC -p- -T5 192.168.37.129 -o nmaplist.txt → ls/cat เทียบผลกับแบบไม่ใส่ -sC
Assignment: ภาพ -sS/-sT แสดง port states · -sV/-O ระบุ version+OS · save file (-oN) + cat ทุกขั้นตอน
