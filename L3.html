สรุปเนื้อหาและปฏิบัติการ Lecture 3: Scanning & Port Scanning Techniques (Nmap)

วิชา Penetration Testing and Protection (0406136051)

1. สรุปเนื้อหาสำคัญ (Theoretical Overview)

  • Scanning Phase: เฟสที่สองของการทำ Pentest มุ่งเน้นการส่งแพ็กเก็ตเข้าไปยังเป้าหมายโดยตรง เพื่อค้นหาเครื่องที่ออนไลน์ (Host Discovery), พอร์ตที่เปิดอยู่ (Open Ports) และบริการที่ทำงานอยู่ (Active Services)
  • จุดประสงค์ของการสแกน (Objectives of Scanning):
    • ตรวจจับระบบที่ยังทำงานอยู่บนเครือข่าย (Live Systems)
    • ค้นหาพอร์ตที่เปิด/ทำงานอยู่
    • ค้นหาระบบปฏิบัติการของเป้าหมาย (Fingerprint)
    • ค้นหาบริการที่ทำงาน/กำลังฟังอยู่บนระบบเป้าหมาย
    • ค้นหา IP Address ของระบบเป้าหมาย (Metasploit มี Discovery Scanner ที่ใช้ Nmap ในตัว)
  • ประเภทของการสแกน (Types of Scanning):
    • Port Scanning: ส่งชุดข้อความเพื่อเรียนรู้ Network Service บนเครื่อง โดยแต่ละบริการผูกกับหมายเลขพอร์ตที่รู้จักกัน (Well-known Port)
    • Network Scanning: ขั้นตอนการระบุโฮสต์ที่ทำงานอยู่บนเครือข่าย เพื่อโจมตีหรือเพื่อการประเมินความปลอดภัย
    • Vulnerability Scanning: กระบวนการอัตโนมัติในการค้นหาช่องโหว่ของระบบคอมพิวเตอร์บนเครือข่าย

2. สถานะของพอร์ต (Port States ใน Nmap)

สถานะ ความหมาย
Open พอร์ตเปิดอยู่และมีแอปพลิเคชันกำลังรับการเชื่อมต่อ (Listening) — ส่ง SYN ไปจะได้ SYN/ACK กลับมา
Closed พอร์ตตอบรับแพ็กเก็ต (ส่ง RST กลับมา) แต่ไม่มีบริการใดรันอยู่
Filtered แพ็กเก็ตถูกบล็อกหรือดักจับโดย Firewall / Packet Filtering (เช่น iptables) ทำให้อ่านสถานะไม่ได้ — มักไม่มีคำตอบกลับมา

3. เทคนิคการสแกนหลัก (Scanning Techniques)

เทคนิค รายละเอียด
TCP Connect Scan (-sT) ทำการจับมือครบ 3 ขั้นตอน (3-Way Handshake: SYN → SYN/ACK → ACK) มีความแม่นยำสูง ไม่จำเป็นต้องใช้สิทธิ์ Root แต่ถูกบันทึก Log ได้ง่าย
SYN Stealth Scan (-sS) ส่งเฉพาะแพ็กเก็ต SYN เมื่อได้รับ SYN/ACK จะส่ง RST กลับไปตัดการเชื่อมต่อทันที (Half-open Scan) ลดการถูกบันทึก Log บนเซิร์ฟเวอร์ปลายทาง (ต้องใช้สิทธิ์ Root/Sudo)
TCP FIN Scan (-sF) ส่ง Flag FIN ไปยังเป้าหมาย — ไม่มีการตอบสนอง = พอร์ตเปิด, ได้ RST กลับมา = พอร์ตปิด
TCP XMAS Scan (-sX) ส่ง Flag FIN + URG + PUSH รวมกัน เหมือนต้นคริสต์มาส — ไม่มีการตอบสนอง = พอร์ตเปิด, ได้ RST = พอร์ตปิด
TCP Null Scan (-sN) ส่งแพ็กเก็ตที่ไม่มี Flag ใดๆ ใน TCP Header — ไม่มีการตอบสนอง = พอร์ตเปิด, ได้ RST = พอร์ตปิด/ถูกกรอง
TCP ACK Scan (-sA) ไม่ใช้เพื่อสแกนพอร์ต แต่ใช้ตรวจสอบกฎ Firewall/ACL ว่ามีการติดตามสถานะ (Stateful) หรือไม่ — ไม่มีคำตอบ = Stateful Filtering, ได้ RST = ผ่านถึงปลายทาง
UDP Scan (-sU) สแกนหาบริการที่ใช้ UDP (เช่น DNS, DHCP, SNMP) — ถ้าได้รับ ICMP Port Unreachable แสดงว่าปิด, ไม่มีคำตอบ = เปิด ใช้เวลาสแกนนานกว่า TCP
TCP FTP Bounce Scan (-b) ให้ FTP Server ส่งไฟล์ไปยังพอร์ตเป้าหมายแทนผู้โจมตี เพื่อปกปิดตัวตน (Attack ผ่าน FTP Server)

4. Host Discovery (การค้นหาโฮสต์)

ขั้นตอนแรกของการทำ Network Pentest คือการรู้ว่าเป้าหมายใดยังทำงานอยู่ วิธีทั่วไปคือการส่ง ICMP Request / Ping และ Nmap ยังใช้สแกนช่วงเครือข่าย (Network Ranges) ได้ด้วย

  • nmap -sP <Target_IP> หรือ nmap -sn <Target_IP> — Ping Scan หาโฮสต์ที่ออนไลน์ (โน้ต: ใน Nmap เวอร์ชันใหม่ option ping scan คือ -sn)
  • nmap -sP 192.168.37.1/24 — สแกนทั้งช่วงเครือข่าย
  • sudo masscan --ports 0-65535 192.168.37.129 — สแกนทุกพอร์ตด้วย Masscan (เร็วกว่า)
  • การสแกนภายนอก (External): จำกัดการสแกนเฉพาะ IP ใน Scope เพื่อเลี่ยงการสแกนเครื่องที่ไม่ได้อนุญาต
  • การสแกนภายใน (Internal): มักสแกนทั้ง Subnet ของ IP ที่เป้าหมายใช้

5. พอร์ตและบริการที่พบบ่อย (Common Ports & Services)

พอร์ต บริการ พอร์ต บริการ

80 HTTP 445 SMB over IP

6. การตรวจจับระบบปฏิบัติการและเวอร์ชันบริการ

  • Service Version Detection (-sV): ส่งโพรบเข้าไปสอบถามเพื่อดึงหมายเลขเวอร์ชันของบริการที่รันอยู่บนพอร์ตนั้นๆ
  • OS Fingerprinting (-O): วิเคราะห์รูปแบบการตอบสนองของ TCP/IP Stack เพื่อระบุประเภทและเวอร์ชันของระบบปฏิบัติการ
  • Aggressive Scan (-A): รวม -sV (เวอร์ชันบริการ), -O (OS Detection), -sC (Default Scripts) และ Traceroute ไว้ในคำสั่งเดียว: nmap -n -A -T5 <Target_IP>
  • สแกนทุกพอร์ต: nmap -p- <Target_IP> — สแกนพอร์ตทั้งหมด 65,535 พอร์ต
  • Timing Option: -T0 (paranoid) ถึง -T5 (insane) ใช้ปรับความเร็ว/ความเนียนในการสแกน

7. การบันทึกผลลัพธ์ลงไฟล์รายงาน (Output Management)

  • Normal Format: nmap -sS <Target_IP> -oN result.txt
  • Greppable Format: nmap -sS <Target_IP> -oG result_greppable.txt
  • XML Format: nmap -sS <Target_IP> -oX result_xml.txt
  • ทุก Format พร้อมกัน (-oA): nmap -sV <Target_IP> -oA lab3_scan_results — สร้างไฟล์ .nmap, .xml และ .gnmap

8. รายละเอียดขั้นตอนปฏิบัติการ Lab (Step-by-Step Practical Guide)

ตอนที่ 1: การค้นหาโฮสต์และการสแกนพอร์ตพื้นฐาน (Host Discovery & Port Scanning)

  • ค้นหาโฮสต์ที่มีชีวิตในเครือข่าย (Ping Sweep): รันคำสั่ง nmap -sn 192.168.56.0/24 เพื่อระบุหมายเลข IP ของเป้าหมายในวงเครือข่าย
  • สแกนแบบ TCP SYN Scan (Stealth Scan): รันคำสั่ง sudo nmap -sS <Target_IP> เพื่อตรวจสอบพอร์ตมาตรฐาน 1,000 พอร์ตแรก
  • สแกนแบบ TCP Connect Scan เจาะจงพอร์ต: รันคำสั่ง nmap -sT -p 80,445,21 <Target_IP> เพื่อระบุสถานะเฉพาะพอร์ตที่สนใจ

ตอนที่ 2: การตรวจสอบเวอร์ชันบริการและระบบปฏิบัติการ (Detection & Fingerprinting)

  • สแกนหาเวอร์ชันของบริการ: รันคำสั่ง nmap -sV <Target_IP> เพื่อตรวจสอบชื่อซอฟต์แวร์และเวอร์ชัน (เช่น Apache, vsFTPd, OpenSSH)
  • สแกนระบุระบบปฏิบัติการ: รันคำสั่ง sudo nmap -O -T4 <Target_IP> เพื่อตรวจหา OS Fingerprint และเพิ่มความเร็วการสแกน
  • สแกนแบบครอบคลุมรอบด้าน (Aggressive Scan): รันคำสั่ง sudo nmap -A <Target_IP> รวมการทำงานของ -sV, -O, -sC (Default Scripts) และ Traceroute ไว้ในคำสั่งเดียว

ตอนที่ 3: การบันทึกผลลัพธ์ลงไฟล์รายงาน (Output Management)

  • บันทึกผลลัพธ์เป็นไฟล์ข้อความมาตรฐาน (-oN): รันคำสั่ง nmap -sT -p 80 <Target_IP> -oN mscan.txt
  • ตรวจสอบข้อมูลในไฟล์: รันคำสั่ง cat mscan.txt เพื่อแสดงผลการสแกนที่ถูกบันทึก
  • บันทึกผลพร้อมกันทุกรูปแบบ (All Formats -oA): รันคำสั่ง nmap -sV <Target_IP> -oA lab3_scan_results เพื่อสร้างไฟล์รายงานทั้งแบบ .nmap, .xml และ .gnmap
แบบฝึกหัดสแกนขั้นสูง: sudo nmap -sS -sV -sC -p- -T5 192.168.37.129 -o nmaplist.txt (อย่าลืมเปลี่ยน IP เป็นของตัวเอง) แล้วใช้ ls และ cat nmaplist.txt ดูผลลัพธ์ จากนั้นเปรียบเทียบกับผลที่สแกนโดยไม่ใช้ -sC

9. สรุปรายการหลักฐานที่ต้องบันทึก (Assignment Checklist)

  • ภาพผลลัพธ์การสแกนแบบ -sS และ -sT แสดงสถานะพอร์ตที่เปิดอยู่ (Open/Closed/Filtered)
  • ภาพผลลัพธ์การรันคำสั่ง -sV และ -O ที่ระบุเวอร์ชันซอฟต์แวร์และ OS ของเป้าหมาย
  • ภาพการรันคำสั่งสแกนพร้อมออปชันบันทึกไฟล์ (เช่น -oN mscan.txt) และภาพคำสั่ง cat เปิดแสดงข้อมูลในไฟล์รายงาน
