สรุปเนื้อหาและปฏิบัติการ Lecture 4: Enumeration & Service Discovery

วิชา Penetration Testing and Protection (0406136051)

1. สรุปเนื้อหาสำคัญ (Theoretical Overview)

  • Enumeration Phase: ขั้นตอนการดึงข้อมูลเชิงลึกจากบริการและพอร์ตที่เปิดอยู่ เพื่อระบุบัญชีผู้ใช้ โฟลเดอร์ที่แชร์ และข้อมูลการตั้งค่าระบบ
  • ความสำคัญของ Enumeration: ช่วยให้เข้าใจว่ามีอุปกรณ์ใดบนเครือข่าย อยู่ที่ไหน และให้บริการอะไร เพื่อนำข้อมูลไปหาช่องโหว่และโจมตี ต้องใช้ทั้งเวลาและความอดทน เพราะเป็นขั้นตอนสำคัญของกระบวนการ Hacking
  • เทคนิคการ Enumeration ที่พบบ่อย:
    • ใช้ Email IDs และ Usernames เพื่อ Brute-force รหัสผ่าน
    • ลองใช้ Default Passwords กับระบบที่ตั้งค่าไม่ปลอดภัย
    • DNS Zone Transfer เพื่อเปิดเผยข้อมูลโครงสร้าง (Topology)
  • กระบวนการ Enumeration:
    • Active Scanning: ส่งคำขอและวิเคราะห์การตอบสนอง — พบโฮสต์ได้ครบกว่า แต่สร้างทราฟฟิกมากและเสี่ยงถูกตรวจจับ
    • Passive Scanning: ฟังทราฟฟิกบนเครือข่ายแล้ววิเคราะห์ — เนียนกว่าแต่พบโฮสต์ได้น้อยกว่า

2. SMB / Samba Enumeration

  • ตรวจสอบรายชื่อไดรฟ์แชร์และสิทธิ์การเข้าถึงด้วย smbclient และ SMBMap
    • smbclient -L \\\\<Target_IP> — ดูรายการแชร์
    • smbmap -H <Target_IP> — แจกแจง Share Drives, ตรวจสิทธิ์, สำรวจเนื้อหา, Upload/Download
  • ดึงรายชื่อผู้ใช้ (Users), กลุ่ม (Groups) และข้อมูลระบบปฏิบัติการด้วย enum4linux
    • -U: แสดงรายชื่อ Usernames (ต้องให้เซิร์ฟเวอร์อนุญาต)
    • -u username -p password: ระบุข้อมูลประจำตัวเพื่อดึงข้อมูล
    • -G: แสดง Groups   -S: แสดง Shares   -o: ดึงข้อมูล OS
    • enum4linux -a <Target_IP> — ดึงข้อมูลทั้งหมดแบบสมบูรณ์

3. User / Group / Share Enumeration ด้วย Nmap NSE

  • User Enumeration: nmap --script smb-enum-users.nse <host> — การรู้รายชื่อผู้ใช้คือก้าวแรกของการ Brute-force Credentials โดยใช้โปรโตคอล SMB (TCP 445)
  • Group Enumeration: nmap --script smb-enum-groups.nse -p445 <host> — ระบุบทบาทการอนุญาต (Authorization Roles) และสมาชิกของกลุ่ม
  • Network Share Enumeration: nmap --script smb-enum-shares.nse -p 445 <host> — ค้นหาระบบที่แชร์ไฟล์/โฟลเดอร์/เครื่องพิมพ์เพื่อสร้าง Attack Surface
  • NBTscan: nbtscan -v -s : 192.168.37.0/24 — สแกน NetBIOS name information; ใช้ NSE script nbstat.nse ได้เช่นกัน: nmap -sV <targetIP> --script nbstat.nse

4. RPC Enumeration (Port 111 / 2049)

  • บนระบบ UNIX พอร์ต TCP 111 ที่เปิดอยู่บ่งชี้ว่ามีบริการ RPC (Remote Procedure Call) ทำงานอยู่
  • ใช้คำสั่ง rpcinfo -p <Target_IP> เพื่อดูโปรแกรม RPC ที่เปิดทำงาน (เช่น portmapper, nfs, mountd)
  • ใช้คำสั่ง showmount -e <Target_IP> เพื่อตรวจสอบไดเรกทอรีที่แชร์ผ่าน NFS (เช่น ไดเรกทอรีราก /*)

5. Web Application Enumeration (Port 80 / 443)

  • ค้นหาพาธไฟล์และไดเรกทอรีที่ซ่อนอยู่ด้วย Nmap Script (http-enum): nmap -p 80,443 --script http-enum <Target_IP> เพื่อหาพาธสำคัญ เช่น /phpMyAdmin/, /phpinfo.php
  • สแกนตรวจสอบช่องโหว่และโครงสร้างเว็บเซิร์ฟเวอร์ด้วย nikto -h <Target_IP> (Open-source Web Vulnerability Scanner)

6. Service & Credential Enumeration

  • ตรวจสอบรายการโพรเซสและบริการบนระบบ Windows ผ่านพอร์ต 445 ด้วยสคริปต์ smb-enum-processes.nse โดยใช้ Credentials ของผู้ใช้ที่มีสิทธิ์อ่านสถานะบริการ: nmap --script smb-enum-processes.nse --script-args smbusername=<username>,smbpass=<password> -p445 <host>
  • การสแกนเพิ่มเติมด้วย nmap -sC จะรัน NSE Scripts ทั่วไปตามพอร์ตที่พบ — เหมาะสำหรับ Fingerprinting แอปพลิเคชันและ OS ที่รันบนโฮสต์

7. รายละเอียดขั้นตอนปฏิบัติการ Lab (Step-by-Step Practical Guide)

ตอนที่ 1: การแจกแจงข้อมูล SMB และ Samba Shares

  • สำรวจบริการและดูโฟลเดอร์แชร์: รันคำสั่ง nmap -sV -p 139,445 <Target_IP> และเชื่อมต่อดูรายการแชร์ด้วย smbclient -L \\\\<Target_IP>
  • ดึงข้อมูลระบบด้วย enum4linux: รันคำสั่ง enum4linux -a <Target_IP> เพื่อตรวจสอบ User accounts, Groups และ OS details แบบสมบูรณ์

ตอนที่ 2: การตรวจสอบบริการ RPC และแชร์ไดเรกทอรี NFS

  • ตรวจสอบโปรแกรม RPC ที่เปิดใช้งาน: รันคำสั่ง rpcinfo -p <Target_IP> เพื่อดูเวอร์ชัน พอร์ต และโปรโตคอลที่ผูกอยู่กับ RPC
  • ตรวจสอบไดเรกทอรีที่เปิดแชร์ (Exported Shares): รันคำสั่ง showmount -e <Target_IP> เพื่อระบุโฟลเดอร์ที่เปิดให้เชื่อมต่อไปยังระบบภายนอก

ตอนที่ 3: การแจกแจงโครงสร้าง Web Application (Web Enumeration)

  • รัน Nmap Script ค้นหาไดเรกทอรีเว็บ: รันคำสั่ง nmap -p 80,443 --script http-enum <Target_IP> เพื่อหาพาธสำคัญ เช่น /phpMyAdmin/, /phpinfo.php
  • สแกนช่องโหว่เว็บเซิร์ฟเวอร์ด้วย Nikto: รันคำสั่ง nikto -h <Target_IP> เพื่อระบุปัญหาการตั้งค่าและไฟล์ที่อาจมีช่องโหว่
ข้อควรจำ: การ Enumeration ที่ดีต้องละเอียดและรอบคอบ — สแกนเฉพาะเป้าหมายใน Scope ที่ได้รับอนุญาต และบันทึกผลลัพธ์ทุกขั้นตอนเพื่อใช้เป็นหลักฐานในรายงาน

8. สรุปรายการหลักฐานที่ต้องบันทึก (Assignment Checklist)

  • ภาพผลลัพธ์การรันคำสั่งสแกนเวอร์ชันเฉพาะพอร์ต เช่น nmap -sV -p 8888 <Target_IP>
  • ภาพผลการทำ TCP Connect Scan บันทึกลงไฟล์ mscan.txt (nmap -sT -p 80 <Target_IP> -oN mscan.txt) พร้อมภาพคำสั่ง cat mscan.txt
  • ภาพผลการแจกแจงข้อมูลระบบจากเครื่องมือ enum4linux, showmount -e หรือ nmap --script http-enum
